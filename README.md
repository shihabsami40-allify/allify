# ALLIFY — Chattogram Digital Bazaar

Bengali-first multi-vendor marketplace for Chattogram, Bangladesh.

## Current status
Source export from Lovable as of 2026-11-11. This is an early MVP foundation, not a complete production marketplace. Product detail, search/category pages, cart, checkout, customer accounts, seller onboarding/dashboard, and admin dashboard still need implementation.

## Security
`.env` and secrets are intentionally excluded. Never commit passwords, tokens, or Supabase service-role keys.

## Stack
TanStack Start, React, TypeScript, Tailwind CSS, Supabase.

## Payments
Cash on delivery/manual confirmation only. Online payments and courier integrations are not configured.
